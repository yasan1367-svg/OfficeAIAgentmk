# سند معماری سیستم Office AI Agent

## ۱. ساختار کلان
پروژه از سه بخش هماهنگ تشکیل شده است:
1. **Office Add-in Task Pane (Client-Side React 19 + TypeScript)**: مسئول رندر رابط کاربری، دریافت فرمان‌های کاربر، نمایش مراحل برنامه و تعامل مستقیم با سند از طریق کتابخانه رسمی Microsoft Office.js.
2. **Local Security & Proxy Server (Express 4)**: مسئول محافظت از API Keyها، جلوگیری از حملات تزریق پرامپت و مسیریابی امن به ارائه‌دهندگان هوش مصنوعی.
3. **AI Adapters & Tool Gatekeeper**: آداپتورهای ارتباطی چندگانه با پشتیبانی از سرویس هوشیار ۲۴، OpenAI و Google Gemini به همراه مکانیزم تأییدیه قبل از اجرای اقدامات پرخطر.

## ۲. دیاگرام جریان تعاملی
```
[کاربر در آفیس ۲۰۲۴ دسکتاپ]
            │
            ▼
   [Office Task Pane UI]
            │ (متن فرمان طبیعی)
            ▼
   [Local Proxy Server]  <───> [فیلتر امنیتی و ماسک‌گذاری کلید]
            │
            ▼
     [ارائه‌دهنده AI] (هوشیار ۲۴ / OpenAI / Gemini)
            │
            ▼ (برنامه اجرایی مرحله‌به‌مرحله)
   [تحلیل سطح ریسک اقدامات]
    ├─ امن: اجرای مستقیم
    └─ حساس: اخذ تأیید صریح در مدال
            │
            ▼
[اجرا از طریق Office.js در اکسل / ورد]
            │
            ▼
 [بازرسی و اعتبارسنجی نتایج واقعی]
```

## ۳. تضمین کیفیت و پایداری در Office.js
- کلیه فراخوانی‌های `context.sync()` به صورت خوشه‌ای (Batch) اجرا می‌شوند تا بار پردازشی اکسل و ورد به حداقل برسد.
- محدوده سلول‌ها پیش از خواندن محدود به محدوده مورد استفاده (`getUsedRange`) می‌گردد تا از فریز شدن آفیس در فایل‌های چند ده هزار ردیفی جلوگیری شود.
- ساختار خطاها با کدهای مشخص و پیام‌های قابل درک به زبان فارسی به کاربر گزارش می‌شود.
